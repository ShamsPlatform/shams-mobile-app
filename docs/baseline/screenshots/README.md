# Screenshot baseline

Captured on a Moto G 5G (2024), Android 14, on 2026-11-15.

- `dark-home.png` and `dark-home-restored.png`: Home in the original dark
  theme.
- `light-home.png` and `light-relaunch.png`: Home after toggling to light and
  after a cold restart.
- `light-workshops.png`, `light-following.png`, and
  `light-notifications.png`: read-only navigation baselines.

The Windows target could not build because its Visual Studio C++ toolchain is
not installed; the Android screenshots are the authoritative Phase 0 baseline.
